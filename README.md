# Secure Network Lab

Lab réseau sécurisé sur 4 VMs Debian 13 (VMware Workstation) : routeur-pare-feu iptables, DMZ web en HTTPS (CA interne), administration par VPN WireGuard, supervision Zabbix/SNMP, analyse de trafic et script de diagnostic.
